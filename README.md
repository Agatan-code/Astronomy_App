# Astronomy_App

This app allows users to view different celestial objects and their related information. Additionally, it enables the users to import images of the night sky into the app, to build on its database.

======================== Set up ========================
You can clone using git or download the zip in your computer and then on your terminal type:

npm install

Next type the following on the terminal, and click on the link that the terminal will provide:

node .\server.js

The link would look like this, and you must click on "http://localhost:3000" to open the app:

Server running on http://localhost:3000
